# against. numpy, scipy, and networkx all contribute to those numbers, so an
# unpinned redeploy could silently shift the demonstration figures backing
# USPTO App. No. 19/641,446 with no code change and no failing test.
#
# These versions are the ones the current golden files were captured with and
# the full stack was verified against. To upgrade: bump here, run
# `python -m tests.regen_golden`, and review any change it reports.
